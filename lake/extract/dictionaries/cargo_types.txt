# cargo_types.txt - request vocabulary for lake/extract/Rules.scala
#
# Format: section|phrase|value      (phrases match as whole words, ignoring case)
#
# cargo    phrase -> cargo type. The longest matching phrase wins. Typos are tolerated: one
#          word of 5+ letters may have one typo (a letter dropped, added, changed, or two
#          neighbouring letters swapped: "crago", "vacines"), and a phrase may be written
#          without its spaces ("generalcargo") or with a typo across a space ("foo daid",
#          "fresh ifsh", "food iad") if it has 7+ letters and no word under 3. Short words ("dg", "kg")
#          must otherwise match exactly, so "kg cargo" is never read as "dg cargo"
# cargo_fallback  used only when no cargo phrase matched ("cargo" alone means general cargo,
#          but "gold, valuable cargo" is valuables)
# shc      phrase -> IATA special handling code. Longest phrase wins ("cold chain 2-8" is
#          PIL, "cold chain" alone is PER)
# unit     weight unit -> kilograms per unit ("2.5T" = 2500 kg)
# not_weight  a number followed by these words is not the shipment weight
#          ("one piece over 3T", "12 pallets", "dims 120x80")
# request  words that mark a message as a cargo request (Rules.scala also needs a route,
#          a cargo type or a weight before it counts a message as a request)
# All entries are project assumptions [A].
